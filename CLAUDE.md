# Nozzleworks quotes

- **Do not create quotes (estimates) in Zoho Books.** When generating a customer quote, produce the quote document only (Word/Excel in `quote-template/`). This overrides the product-quote skill's "Zoho Books sync (automatic on every quote)" step. Only touch Zoho if the user explicitly asks for it in that request.
- Before choosing a quote number, check SharePoint (`02 Sales/05 Quotation`) as well as Zoho. Zoho's list is not complete.
